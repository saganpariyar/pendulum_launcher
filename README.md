# Pendulum Launcher (Wrecking Tether)

A 2D co-op physics puzzle-action Flutter game where the **Light** runner grapples onto overhead ceiling hooks, turning the **Heavy** companion into a kinetic wrecking ball to smash fortified barriers.

## Features
- **6 Progressive Demolition Levels** with multi-hit stone, crystal, and iron fortress barriers, ceiling pivots, and spike pits.
- **Customization Studio (4 Options Per Selection):**
  - 4 Light Pivot Profiles, 4 Heavy Wrecking Ball Profiles, 4 Fortress Backgrounds (`Crystal Vault`, `Obsidian Siege`, `Clockwork Hall`, `Asteroid Quarry`), 4 Tether Styles, and 4 Pilot Emblem Badges.
- **Solo Swap & 2P Local Split Controls** + Keyboard (`WASD` / `Arrow Keys` / `Space` / `Enter` / `Tab`).

## Run
Double-click `run_app.bat` or run:
```bash
flutter run -d chrome
```
